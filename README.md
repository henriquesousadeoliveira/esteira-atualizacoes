# Iurix — instaladores

Aplicativo de automação jurídica: extrai as íntegras dos processos dos tribunais
para o Google Drive e distribui as peças produzidas no EasyJur.

## Baixar

Abra a **[versão mais recente](https://github.com/henriquesousadeoliveira/iurix-atualizacoes/releases/latest)**
e baixe o arquivo do seu computador:

| Computador | Arquivo |
|---|---|
| Windows 10 ou 11 | `Iurix-…-Windows.exe` |
| Mac com chip Apple (M1, M2, M3, M4) | `Iurix-…-macOS-AppleSilicon.dmg` |
| Mac com processador Intel | `Iurix-…-macOS-Intel.dmg` |

**Windows:** dê dois cliques no arquivo. Se aparecer "O Windows protegeu o
computador", clique em *Mais informações* → *Executar assim mesmo*.

**Mac:** abra o arquivo e arraste o Iurix para *Aplicativos*. Na primeira
abertura, se o Mac recusar, vá em *Ajustes do Sistema → Privacidade e
Segurança* e clique em *Abrir Mesmo Assim*.

Depois de instalado, o próprio Iurix avisa quando houver versão nova e se
atualiza com um clique.

---
Este repositório contém apenas os instaladores. Cada versão traz o arquivo
`SHA256SUMS.txt`, que o aplicativo usa para conferir a integridade dos
downloads antes de instalar.
